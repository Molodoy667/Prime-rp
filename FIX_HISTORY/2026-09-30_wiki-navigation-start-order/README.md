# FIX: Wiki, навигация и порядок шагов старта

Дата

2026-09-30

Статус

TESTING

## Проблема

- На мобильной Wiki-версии был виден встроенный водяной знак Ukraine GTA на карточках скинов.
- В навигации присутствовал лишний пункт «Магазин».
- Hash-ссылки из шапки и футера не переводили пользователя с вложенной страницы на главную.
- В блоке «Як почати» первым показывался аккаунт, а не лаунчер.

## Корневая причина

Водяной знак подтверждён внутри исходных PNG-файлов `public/assets/skins/130x160`, а не в отдельном HTML-элементе. Для него добавлено единое визуальное перекрытие нижней части Wiki-карточки, одинаковое для desktop и mobile. Для переходов использовались относительные hash-ссылки вроде `#home`, поэтому браузер искал якорь только в текущем маршруте.

## Как работает система

`Header` и `Footer` формируют ссылки навигации → hash-ссылки преобразуются в URL вида `/#section` → приложение открывает корневой маршрут и прокручивает к секции. Wiki выводит PNG скина внутри `.wiki-skin-card .wiki-card-image`; CSS-карточка закрывает нижнюю часть изображения.

## Исследованные файлы

- `src/components/Header/index.tsx` — desktop/mobile навигация.
- `src/components/ui/index.tsx` — общий логотип `Brand`.
- `src/components/HowToStart/index.tsx` — порядок карточек старта.
- `src/components/Footer/index.tsx` — нижняя навигация и hash-ссылки.
- `src/components/Wiki/index.tsx` — DOM-класс и источник изображений Wiki-скинов.
- `src/styles/global.css` — размеры Wiki-карточек и адаптивные стили.
- `src/main.tsx` — корневой маршрут и маршруты вложенных страниц.

## Изменённые файлы

- `src/components/Header/index.tsx` — добавлен перевод hash-ссылок в `/#...`; удалён «Магазин» из desktop/mobile шапки.
- `src/components/ui/index.tsx` — логотип ведёт на `/#home`.
- `src/components/HowToStart/index.tsx` — порядок стал: лаунчер, аккаунт, вход в мир; ссылка на сервер стала `/#servers`.
- `src/components/Footer/index.tsx` — удалён «Магазин», hash-ссылки ведут через корень.
- `src/styles/global.css` — добавлено единое перекрытие нижней части Wiki-скин карточки для скрытия встроенного watermark.

## Исследованные, но НЕ изменённые

- `src/components/Wiki/index.tsx` — существующий класс `wiki-skin-card` уже позволяет применить CSS без изменения JSX.
- `src/main.tsx` — маршрутизация соответствует переходам через `/` и якорь.
- `public/assets/skins/130x160/*.png` — исходные изображения не перезаписывались.

## Что конкретно исправлено

Навигация теперь использует корневые якоря для секций главной страницы, поэтому переход работает и с `/wiki`, `/donate` и других вложенных маршрутов. Пункт «Магазин» убран из двух навигационных областей. Карточки старта переставлены без изменения их содержимого. CSS-overlay применяется к Wiki skin cards на всех размерах viewport.

## Почему выбран именно этот fix

Источник водяного знака находится в PNG, а не в React-разметке. Не изменялись исходные игровые изображения и не добавлялась массовая перерисовка ассетов; визуальное решение ограничено Wiki-карточками и сохраняет текущую загрузку файлов.

## Риски

Нижняя часть фигур на Wiki-карточках может быть частично закрыта вместе с watermark. Исходные PNG и другие разделы сайта не затрагиваются.
