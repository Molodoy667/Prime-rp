# PRIME RP

Завершена головна сторінка українського MTA RolePlay-проєкту. React + TypeScript + Vite, Tailwind CSS, Framer Motion та Lucide React. Легкі ефекти глибини реалізовані CSS і Motion, без WebGL.

## Запуск

```sh
npm ci
npm run dev
npm run build
```

## Підключення офіційних сервісів

У `src/config/site.ts` замініть `#` на перевірені адреси форуму, магазину, кабінету, лаунчера, соціальних мереж та юридичних документів. Непідключені посилання відкривають доступне інформаційне вікно; сторінка не імітує реєстрацію, платежі або завантаження. `trailerUrl` призначений для прямого URL відеофайлу.

## Реальний моніторинг MTA

Same-origin `GET /api/server-status` отримує офіційний бінарний список MTA через HTTPS: `https://master.multitheftauto.com/ase/mta/`. Worker розбирає формат v2 й вибирає тільки `94.23.168.153:22097`. Ніки гравців не зберігаються та не повертаються. API не приймає довільні IP/URL від відвідувача.

Повертаються назва, ліміт, доступний онлайн, час перевірки, час оновлення джерела та стан відповіді. Дані кешуються 30 секунд; клієнт перевіряє їх кожні 60 секунд і після повернення до вкладки. Master list має власну затримку: це не прямий UDP-запит до сервера. Відсутній запис означає «статус невідомий», а не автоматично offline. Позначка MTA про відсутність відповіді показується як «не відповідає». Дані старші за п’ять хвилин або без підтвердженого часу не відображаються як поточний онлайн. Помилки не замінюються mock-даними. Нуль коректно показується лише для сервера, що відповідає за даними джерела.

Під час першої перевірки 16 вересня 2026 року запис адреси мав назву `SILVER [ #01 ]`, ліміт 90 та ознаку відсутності відповіді. Ці значення не зашиті у frontend. Для зміни адреси синхронно оновіть `worker/status.mjs` і `src/config/site.ts`. Кнопка приєднання відкриває `mtasa://94.23.168.153:22097`.

Сайт тепер публікується як Cloudflare-compatible ESM Worker із frontend-ресурсами всередині bundle. Нові npm-бібліотеки у браузер не додані. Dev-сервер Vite також обслуговує API через той самий handler. `npm run test:server` перевіряє парсер, точний IP/порт, онлайн 0, стан без відповіді, застарілі/відсутні дані й пошкоджені відповіді.

Новини залишаються демонстраційними: `useMockNews`, `newsApiUrl`, `src/data/content.ts`. Географічні локації також налаштовуються у `src/data/content.ts`. Львів і Одесу прибрано; Бориспіль і Конча-Заспа додані з приблизними географічними координатами; Румунія має окремий контур. Михайлівка доступна в списку локацій без вигаданої точки — потрібно уточнити населений пункт.

## Компоненти

Header, Hero, ServerStatus, Features, Careers, Vehicles, UkraineMap, HowToStart, News, Gallery, FinalCTA та Footer знаходяться в окремих каталогах. Спільні UI-компоненти — `src/components/ui`, паралакс — `src/hooks/useParallax.ts`. Карта та модальні вікна мають окремі динамічні chunks.

## Графіка й шрифти

- Офіційний наданий користувачем постер збережено як `public/assets/official-brand-original.webp`. Для розміщення поверх Hero його центральний логотип відокремлено від фону засобом imagegen (`logo.webp`).
- Hero, місто, автомобіль і десять професій — оригінальні AI-концепт-арти, створені для цієї сторінки. Це не скриншоти гри та не підтвердження доступності контенту.
- WebP-варіанти 800/1600 px, `srcSet`, розміри зображень і lazy loading. Preload має лише critical hero artwork. Атлас професій завантажується при наближенні секції до viewport.
- Локальні Manrope й Oswald, отримані через Google Fonts; перевірено символи ІіЇїЄєҐґ. Ліцензія SIL Open Font License; тексти ліцензій у `public/assets`.
- Контури України та Румунії — public-domain Natural Earth, наданий [johan/world.geo.json](https://github.com/johan/world.geo.json/blob/master/countries/UKR.geo.json), включно з Кримом. Дані спрощені для стилізованої інтерактивної мапи.
- [Ukraine GTA](https://ukraine-gta.com.ua/uk/) переглянуто лише як функціональний референс. Їхні графічні матеріали не використано.

## Доступність і перевірка

Семантичні секції, skip link, focus-visible, native modal dialog з Escape і поверненням фокуса, клавіатурні tabs професій, кнопки міських точок, клавіші ←/→ для галереї. `prefers-reduced-motion` вимикає паралакс і декоративний рух. Native scroll збережено.

Успішно перевірено TypeScript, production build, локальні посилання на assets, responsive image dimensions, цілі anchor navigation і українські символи у шрифтах. CSS має адаптивні стани для desktop, tablet і phone. Браузерний прогін та FPS-вимірювання в цьому сеансі не проводилися.

Моніторинг сервера підключено. Авторизація, платежі, офіційний лаунчер і зовнішні посилання ще потребують підключення перед публічним запуском.
